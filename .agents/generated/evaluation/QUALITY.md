# Quality — what this host declared it judges, and what has never been judged

> PROJECTION. Do not edit: delete this whole plane and run `render`, and it comes back byte-identical.
> Kit version 0.1.6 · project status accepted.

**No judgement is listed on this page, and that is deliberate.** A judgement changes after it is
written — it is opened `UNJUDGED` and rewritten when something judges — so a page that listed
verdicts would be stale in the instant it was correct. The live reading is `evaluate`, which states
the measure at the moment you ask it, and `check`, which reads the records the same way.

What is on this page is the GRAMMAR, and this host's own declaration of what it judges.

## What a judgement claims

A run's receipt proves that it **fired**. A judgement is the other question — did it **hit** — and
the framework ships no answer to it. The verdict vocabulary is `UNJUDGED · PASS · FAIL ·
INCONCLUSIVE`; what earns any of them is this host's, declared in this host's rubrics, applied by
this host's judges. There is no scale here and no number: how much better one answer is than another
is a thing only a domain can say.

## The rubrics this host declared

**THE MEASURE IS ZERO.** This host has declared no rubric, so nothing here has been judged, and this
page says so rather than reporting that everything is fine. A zero measure is not a good score and
not a bad one — it is the absence of a measure, which is the state every host starts in and the one
an evaluation surface most often hides. The framework ships no rubric of its own on purpose: a good
answer is a property of a domain, and the only rubric it could write would be an opinion about a
subject it was never given.

## Who judges here

**THE MEASURE IS ZERO.** This host has declared no judge, so no verdict written here could be traced
to an author.

### Who judges the judge

Nothing in this kit measures a judge. A judge's agreement with a sample somebody trusts — the one
thing that would make its verdicts evidence rather than testimony — **is not measured anywhere
here**. A judgement is trusted exactly as far as this host trusts the judge named on it, and no
further. This is a declared limit, not an oversight, and it is on this page so that no one can
mistake an unmeasured judge for a measured one.

## How a judgement is read

### a-verdict-that-cannot-say-who-reached-it

- because this record says a case was judged good and cannot say by whom. Nothing in this kit measures a judge -- there is no sample it agrees with, no rate it is held to -- so the roster is the entire basis on which a host trusts a verdict, and a verdict off the roster has no basis at all. It will go on certifying, and it will do it most convincingly the longer it sits there.
- instead written by a judge the host declared, whose id is on this record and whose reason for being trusted is in the declaration beside it.
- calibrated on the judgement it must match, `11111111111111111111111111111101`, and the lookalike it must tolerate, `11111111111111111111111111111102`

### a-refusal-that-cannot-say-who-reached-it

- because an accusation with no author is worse than a certificate with none. Somebody will have to answer for this verdict and there is nobody to ask what was read, so the finding cannot be argued with, only obeyed or ignored -- and both are how a quality signal stops being used.
- instead written by a judge the host declared, so that a finding can be taken up with whoever, or whatever, reached it.
- calibrated on the judgement it must match, `22222222222222222222222222222201`, and the lookalike it must tolerate, `22222222222222222222222222222202`

### a-verdict-that-cannot-be-placed-in-time

- because the record says the case was read and found good, and cannot say when. A reading that carries no moment cannot be contradicted, only believed: the case may have been rewritten the same afternoon and this verdict would still read as current to every reader who finds it.
- instead closed by whatever judges, stating its moment in the same act as its verdict, so that a judgement can be aged, compared, and eventually re-asked.
- calibrated on the judgement it must match, `33333333333333333333333333333301`, and the lookalike it must tolerate, `33333333333333333333333333333302`

### a-refusal-that-cannot-be-placed-in-time

- because a failure with no moment is read as current for as long as it sits there, and the case it belongs to may have been fixed long ago -- so the surface reports a fault the host no longer has, which is the same lie as reporting none it does.
- instead closed by whatever judges, stating its moment in the same act as its verdict, so that a failure can be dated and left behind.
- calibrated on the judgement it must match, `44444444444444444444444444444401`, and the lookalike it must tolerate, `44444444444444444444444444444402`

None of them reads a verdict as wrong. Whether `PASS` was deserved is the domain's question; what is
read here is only whether the record can be questioned at all.

There is no threshold and no tolerance: **there is no observe-then-enforce period; the first crossing
is a finding.** The number at which observing becomes enforcing has never been declared anywhere in
this framework, and a field nobody filled in would read as enforced.

Nothing is ever removed. A judgement is evidence, and evidence is not swept up by the thing being
questioned.
