A depth is a distance and never a verdict. The number that would turn a distance into a verdict
does not exist (ADR-019 decision 5): a hop limit would fail a well-routed document for being deep
and pass a badly-routed one for being shallow. The unreachable are counted here and not named —
what makes an unreachable document a defect is what it OWES, and that reading belongs to the gate
that holds obligations, which states it by name on every run.

## What this page deliberately does not state

- **A recommended route.** Every trigger here was written by this host in its own map. The kit
  ships no default entry and invents no `read_when`; a page that supplied one would be publishing a
  stance into a host that never declared it.
- **A question no row asked.** There is no `answers` vocabulary of this page's own. Where a place
  says nothing about when to read it, this page says exactly that.
- **Anything about documents the map does not place.** The walk is over the residents of declared
  places. A corpus-wide walk would need an exclusion list living in an interpreter — policy in the
  machinery — and would report on a tree this host never mapped.
