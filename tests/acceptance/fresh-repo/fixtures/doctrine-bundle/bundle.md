# ethics-example — a doctrine bundle published by somebody who is not this kit

*Vendor, of this bundle. Replaced wholesale by its publisher; never edited where it landed.*

This bundle exists as an acceptance fixture. It stands where a company's or a team's own doctrine
would stand, and it proves the only claim that matters about the carrier: a bundle is an ordinary
capability, and no interpreter in the kit knows that any of this is doctrine.

A host that holds this bundle never edits the documents in it. It answers them, by address, in
its own plane.
