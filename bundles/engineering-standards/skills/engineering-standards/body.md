# Engineering standards -- a catalog read by chapter

Generic and domain-free. Read the ONE chapter your task touches; the index below is all that loads
when this skill is activated, and every chapter is read on demand.

## How to use it

1. **Select, don't apply all.** Pick the few styles and patterns that fit this repository's stack and
   stage; the rest is vocabulary, not a checklist. This host's own selections are its stances, below.
2. **Name the trade-off** of every significant choice -- the quality attribute gained and the one lost
   (chapter 4) -- and record it as an ADR in this host's decisions home, with its rejected alternatives.
3. **Harden it.** Turn the invariant the choice creates into an edit gate or a fitness function that
   `check` runs, and record the standard it meets in the conformance map: a rule held only by a comment
   is not held.
4. **Refuse the anti-patterns** (chapter 3).
