# Doctrine bundles -- published beside the kit, never inside it

Each directory here is ONE complete capability carrying conduct doctrine (ADR-004 decision 3,
ADR-021 decision 2): cardinals, chapters, later skills and playbooks. The issued kit ships none of
it and renders the doctrine in force as NONE until a host takes one. A host takes a bundle the way
it takes an adapter -- into its take plane, beside the pinned kit (ADR-018):

    python .agents/kit/interpreters/cli.py take --root . --path bundles/<id> --approve <who>

then enables `<id>` in `.agents/project/project.json`, runs `init --approve <who>` to attest the
pin, and answers each published address with a stance in its own law page. A host never edits a
bundle where it landed; its publisher replaces it wholesale.
