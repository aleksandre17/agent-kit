# Reference — what is true now

> **Kind: REFERENCE.** This kind DESCRIBES; it never commands. Nothing written here binds anyone,
> however correct it is. If something on this shelf turns out to be a rule, it does not become one
> by being read — it is promoted to a decision under `docs/decisions/`, or it stays description.

> SEED. Created once, then owned by this host.

Reference pages state what is presently true: the shape of the system, the vocabulary in use, the
inventory of what exists. They go stale, and a stale reference is a known hazard rather than a
lie — so each page is worth more when it says *when it was last measured* than when it merely
sounds current.

The other kinds live beside this one, and what each of them is for is explained in
`.agents/kit/capabilities/knowledge/payload/knowledge.md` (in the pinned kit). Which of them may DECLARE is stated in exactly one place —
the `knowledge` capability's own declaration, which is also what the `FF-KIND-AUTHORITY` gate
reads. No page repeats that list, including this one: a table with two homes drifts while both
copies still read as correct.
